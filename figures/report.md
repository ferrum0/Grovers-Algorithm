# Break-even analysis

Cost model: a Grover attempt costs k oracle queries plus 1 classical query to verify the measured candidate, repeated until success, so E_q = (k+1)/p. Classical brute force without replacement needs E_c = (N+1)/(M+1). Advantage = E_c / E_q; below 1, classical search would have been the better choice.
